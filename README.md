# نظام سعد السيف — Life OS

نظام تشغيل شخصي للحياة. صفحة واحدة تفتحها كل صباح فتدير منها جوانب حياتك كلها:
لوحة الجوانب، تخطيط اليوم بالكتل الزمنية، العادات، الأهداف، المراجعة، وأدواتك اليومية.

بُني على فلسفة واحدة: **قلّل الحمل الذهني**. أقل نقرات، أقل ألوان، أقل ضجيج.

---

## ما بداخل النظام

| الشاشة | ماذا تفعل |
|---|---|
| **الرئيسية** | شبكة الجوانب (١٢ جانباً) + ويدجتس قابلة للترتيب والإخفاء |
| **تخطيط اليوم** | شريط ساعات بنصف ساعة · اسحب المهمة إلى وقتها · أولويات اليوم الثلاث · مراجعة اليوم |
| **المهام** | كل المهام مع فلاتر (مفتوحة / مستحقّة اليوم / منجزة) |
| **الملاحظات** | صندوق وارد للالتقاط السريع + ملاحظات مصنّفة بالجوانب |
| **المراجعة** | أسبوع كامل: العادات، أين ذهب وقتك، المزاج، مراجعات الأيام |
| **صفحة كل جانب** | مساحة عمل مستقلة تُبنى من أقسام تختارها أنت |

### أنواع الأقسام (محرّك التخصيص)
كل جانب يتكوّن من أقسام تضيفها وتحذفها وتعيد ترتيبها بحرّية:

`مهام` · `عادات` · `أهداف` · `ملاحظات` · `مؤشّر رقمي` (كالوزن — برسم بياني) ·
`سجلّات` (بحقول تحدّدها أنت — كالتحاليل والمواعيد) · `قائمة تحقّق` (يومية أو ثابتة) ·
`يوميّات` (مدخلات مؤرّخة) · `الصلوات الخمس`

### الويدجتس
يومي الآن · مؤقّت التركيز (بومودورو) · التقاط سريع · العادات · أهداف الأسبوع ·
مواقيت الصلاة · الطقس · أدواتي (ChatGPT · Gmail · WhatsApp · التقويم…) · ملاحظة مثبّتة ·
مراجعة اليوم · تقويم الشهر

### اختصارات
`⌘K` بحث وتنقّل · `N` مهمة · `C` التقاط · `T` تخطيط اليوم · `D` الرئيسية

## التشغيل

النظام ملفات ثابتة — لا يحتاج بناءً ولا Node.

```bash
cd public && python3 -m http.server 8080
# افتح: http://localhost:8080/app/
```

يعمل فوراً في **الوضع المحلي**: كل البيانات في متصفحك (localStorage).

---

## ربط قاعدة البيانات (للمزامنة بين الأجهزة)

**١. أنشئ مشروع Supabase باسمك** على [supabase.com](https://supabase.com) — أنت المالك.

**٢. شغّل قاعدة البيانات**
SQL Editor ← New query ← الصق محتوى [`supabase/life_os.sql`](supabase/life_os.sql) ← Run.

**٣. فعّل الدخول**
Authentication ← Providers ← فعّل **Email**.

**٤. الصق المفتاحين** في أول [`public/app/js/core.js`](public/app/js/core.js#L8-L9):

```js
const SUPA_URL = 'https://xxxx.supabase.co';   // Settings ← API ← Project URL
const SUPA_KEY = 'sb_publishable_xxxx';         // Settings ← API ← publishable key
```

بمجرّد تعبئتهما تظهر شاشة الدخول، وتُحفظ بياناتك سحابياً وتتزامن على كل أجهزتك.

> **الأمان:** مفتاح `publishable` ظاهر في الكود وهذا طبيعي — الحماية الحقيقية من `RLS`
> المفعّلة في ملف SQL، وهي تمنع أي شخص من قراءة بيانات غيره.
> لا تضع مفتاح `service_role` في كود الواجهة أبداً.

## البنية

```
public/app/
  index.html        الهيكل + التصميم (نظام رموز واحد، فاتح وداكن)
  js/core.js        الحالة · التخزين · المزامنة · النوافذ · الأدوات
  js/widgets.js     الويدجتس
  js/areas.js       الجوانب · محرّك الأقسام · المهام
  js/timebox.js     تخطيط اليوم بالكتل الزمنية
  js/app.js         التوجيه · اللوحة · المراجعة · الإعدادات · الدخول
  wallpapers/       خلفيات اختيارية
public/fonts/       خط ثمانية
supabase/life_os.sql  قاعدة البيانات + RLS
test/smoke.js       اختبار يشغّل كل الشاشات والعمليات
```

كل البيانات في مستند JSON واحد (`life_state.data`) — بسيط، سريع، ويعمل دون اتصال.

### الاختبار

```bash
node test/smoke.js
```

يشغّل كل شاشة وكل ويدجت وكل جانب و١٦ عملية أساسية في بيئة DOM مصغّرة.
